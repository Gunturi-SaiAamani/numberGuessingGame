A Number guessing game using html,css and javascript

**Technologies used**
*HTML5
*CSS3
*JavaScript

**how to use**
*the game generates a random number upon loading of the page.
*then you can randomly guessing a number.
*if the number you guessed is higher than the randomly guessed number the website displays that it is higher.
*else if the number you guessed is lower than the randomly guessed number the website displays that it is lower.
*if you guess the number correctly the website displays that your guess is correct.

**what i learnt by this**
* DOM manipulation using JavaScript to capture user input and update the screen in real-time.
* Handling user events like button clicks and form submissions.
* Writing conditional statements to control the game logic and compare numbers.
* Structuring a clean webpage with HTML and styling it to look modern with CSS.
